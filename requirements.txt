# Voice Input Framework - Master Requirements
#
# Usage:
#   pip install -r requirements.txt
#
# Plus platform-specific files:
# ─────────────────────────────────────────────────────
# Platform         | STT Server              | LLM Server
# ─────────────────────────────────────────────────────
# Windows CUDA     | requirements/stt-cuda   | requirements/llm-cuda
# Apple Silicon    | requirements/stt-mlx    | requirements/llm-mlx
# CPU (fallback)   | requirements/stt-cpu    | (not recommended)
#
# Examples:
#   STT only (Windows 4090):
#     pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
#     pip install -r requirements.txt
#     pip install -r requirements/stt-cuda.txt
#
#   STT + LLM (Windows 4090):
#     pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
#     pip install git+https://github.com/huggingface/transformers.git  # for Qwen3.5
#     pip install -r requirements.txt
#     pip install -r requirements/stt-cuda.txt
#     pip install -r requirements/llm-cuda.txt
